## 概要

CPU(Centrarl Processing Unit)やGPU(Graphics Processing Unit)と同じようなノリでNPUだのTPUだのが出てくる昨今。定着しているものからそうでないものまで様々だが、それら「ナントカ・プロセッシング・ユニット」をまとめて一覧にしたもの。

## レギュレーション

-   「xxx処理装置」としての意味を持つものが対象（例: XXX太平洋大学等は対象外）
-   できるだけメジャーそうなものを独断で採用
-   でも中には誰も使っていないようなマイナーなものも
-   めぼしい和訳が無かったものは適当に訳した

## 一覧

### APU

-   [Accelerated Processing Unit（加速処理装置）](https://ja.wikipedia.org/wiki/AMD_Accelerated_Processing_Unit)
    -   GPUを内蔵したCPU. AMDの商標なので、Intelだと「統合グラフィックス」とかになる
    -   「加速処理装置」って和訳は変と思うかもしれないが、なんと[特許庁の資料](https://www.jpo.go.jp/resources/report/document/gaikoku/taiwan_201704.pdf)に出てくる
-   [Audio Processing Unit (音響処理装置)](https://www.nvidia.com/en-us/drivers/apu/)
    -   NVIDIAの商標

### BPU

-   [Basic Processing Unit（基本処理装置）](https://www.weblio.jp/content/%E5%9F%BA%E6%9C%AC%E5%87%A6%E7%90%86%E8%A3%85%E7%BD%AE)
    -   命令実行に関わる処理装置の総称らしいが聞いたことないかも
-   [Brain Processing Unit（脳オルガノイド処理装置）](https://www.softbank.jp/corp/technology/research/bpu/)
    -   培養神経細胞コンピューティングの文脈

### CPU

-   [Central Processing Unit（中央処理装置）](https://ja.wikipedia.org/wiki/CPU)
    -   言わずもがな

### DPU

-   [Data Processing Unit（データ処理装置）](https://ja.wikipedia.org/wiki/%E3%83%87%E3%83%BC%E3%82%BF%E3%83%BB%E3%83%97%E3%83%AD%E3%82%BB%E3%83%83%E3%82%B7%E3%83%B3%E3%82%B0%E3%83%BB%E3%83%A6%E3%83%8B%E3%83%83%E3%83%88)
    -   おもにNIC上で通信データの暗号化・復号化などの処理を担う
-   [Deep learning Processor Unit (深層学習処理装置)](https://www.xilinx.com/products/intellectual-property/dpu.html)
    -   AMDの商標

### EPU

-   [Energy Processing Unit（消費電力処理装置）](https://ja.wikipedia.org/wiki/EPU)
    -   ASUSの商標. マザーボード上の各装置の電力消費を監視・制御する装置らしい
-   [Emotion Processing Unit（感情処理装置）](https://en.wikipedia.org/wiki/Emospark)

### FPU

-   [Floating Point Unit（浮動小数点演算処理装置）](https://ja.wikipedia.org/wiki/FPU)
    -   浮動小数点演算を専門に行う処理装置
    -   現代ではCPU内部のサブユニットになっていることが多い

### GPU

-   [Graphics Processing Unit（画像処理装置）](https://ja.wikipedia.org/wiki/GPU)
    -   言わずもがな
    -   またの名をGyouretsu Processing Unit

### HPU

-   [Hogel Processing Unit（ホーゲル処理装置）](https://en.wikipedia.org/wiki/Hogel_processing_unit)
    -   3次元映像描画関連
-   [Holographic Processing Unit（ホログラフィック処理装置）](https://en.wikipedia.org/wiki/Microsoft_HoloLens)
    -   Microsoftの商標. AI関連

### IPU

-   [Infrastructure Processing Unit（インフラストラクチャ処理装置）](https://ja.wikipedia.org/wiki/%E3%83%87%E3%83%BC%E3%82%BF%E3%83%BB%E3%83%97%E3%83%AD%E3%82%BB%E3%83%83%E3%82%B7%E3%83%B3%E3%82%B0%E3%83%BB%E3%83%A6%E3%83%8B%E3%83%83%E3%83%88)
    -   DPUと同義
-   [Image Processing Unit（画像処理装置）](https://en.wikipedia.org/wiki/Image_processor)
    -   和訳するとGPUと区別がつかないが、こっちは主にデジカメとかの画像処理チップを指すイメージ
-   [Inteligence Processing Unit（知能処理装置）](https://en.wikipedia.org/wiki/Graphcore)
    -   AI関連

### JPU

-   [JPEG Processing Unit（JPEG処理装置）](https://www.renesas.com/en/document/pre/product-specifications-r-car-m1-series)
    -   JPEGのハードウェアデコーダ
    -   ルネサスが使ってる用語らしい. 流石にJapanを意識している訳ではないか？

### KPU

-   [Knowledge Processing Unit（知識処理装置）](https://www.stillwater-sc.com/knowledge-processing-unit-tm)
    -   AI関連

### LPU

-   [Language Processing Unit（言語処理装置）](https://groq.com/wp-content/uploads/2024/07/GroqThoughts_WhatIsALPU-vF.pdf)
    -   Groqが出してるLLM用のやつ

### MPU

-   [Micro-Processing Unit（超小型処理装置）](https://ja.wikipedia.org/wiki/%E3%83%9E%E3%82%A4%E3%82%AF%E3%83%AD%E3%83%97%E3%83%AD%E3%82%BB%E3%83%83%E3%82%B5)
    -   いわゆるマイコン用

### NPU

-   [Neural Processing Unit（神経ネットワーク処理装置）](https://en.wikipedia.org/wiki/AI_accelerator)
    -   AIの演算処理、特にニューラルネットワークの処理に特化したプロセッサ

### OPU

-   [Optical Processing Unit（光演算処理装置）](https://engineer.fabcross.jp/archeive/220325_optical-processing-unit.html)
    -   光コンピューティングにおける演算処理装置

### PPU

-   [Physics Processing Unit（物理演算処理装置）](https://en.wikipedia.org/wiki/Physics_processing_unit)
    -   ここでいう「物理」とはおもに「物理エンジン」のこと
-   [Picture Processing Unit（画面処理装置）](https://www.nesdev.org/wiki/PPU)
    -   ファミコンの画面描画処理用の専用装置
-   [Parallel Processing Unit（並列処理装置）](https://flow-computing.com/technology/)

### QPU

-   [Quantum Processing Unit（量子演算処理装置）](https://blogs.nvidia.co.jp/blog/what-is-a-qpu/)
    -   量子コンピューティングにおける演算処理装置

### RPU

-   [RAID Processing Unit（RAID処理装置）](https://en.wikipedia.org/wiki/RAID_processing_unit)
    -   パリティ計算とかを高速で出来るらしい
-   [Ray Processing Unit（光線演算処理装置）](https://en.wikipedia.org/wiki/Ray-tracing_hardware)
    -   3DCGのレイトレーシングに特化した処理装置
-   [Radio Processing Unit（無線処理装置）](https://en.wikipedia.org/wiki/Baseband_processor)
    -   ベースバンドプロセッサ（Baseband processor）と呼ぶことの方が多い
-   [Real-time Processing Unit（リアルタイム処理装置）](https://adaptivesupport.amd.com/s/article/767924)
    -   リアルタイム性が要求される処理（車載システムとか）に特化しているらしい

### SPU

-   [Sound Processing Unit（音声処理装置）](https://ja.wikipedia.org/wiki/SPU)
    -   プレステとかPS2のPCM音源として使われていたらしい
-   [Streaming Processing Unit（ストリーミング処理装置）](https://www.fluvio.io/docs/latest/fluvio/concepts/architecture/spu/)

### TPU

-   [Tensor Processing Unit（テンソル処理装置）](https://ja.wikipedia.org/wiki/%E3%83%86%E3%83%B3%E3%82%B5%E3%83%BC%E3%83%BB%E3%83%97%E3%83%AD%E3%82%BB%E3%83%83%E3%82%B7%E3%83%B3%E3%82%B0%E3%83%BB%E3%83%A6%E3%83%8B%E3%83%83%E3%83%88)
    -   AI関連の行列演算に特化しているという説明
    -   要は並列度の高い半精度浮動小数点演算装置という認識

### UPU

-   [Unified Processing Unit（統合処理装置）](https://www.cnx-software.com/2014/10/15/icube-mvp-socs-combine-cpu-and-gpu-into-a-single-unified-processing-unit-upu/)
-   [Unsupervised Processing Unit（非管理処理装置）](https://arxiv.org/abs/2012.06720)

### VPU

-   [Vector Processing Unit（ベクトル処理装置）](https://en.wikipedia.org/wiki/Vector_processor)
    -   ベクトル計算機（Vector processor）と呼ぶことの方が多い
-   [Vision Processing Unit（視覚処理装置）](https://ja.wikipedia.org/wiki/%E3%83%93%E3%82%B8%E3%83%A7%E3%83%B3%E3%83%BB%E3%83%97%E3%83%AD%E3%82%BB%E3%83%83%E3%82%B7%E3%83%B3%E3%82%B0%E3%83%BB%E3%83%A6%E3%83%8B%E3%83%83%E3%83%88)
    -   AI関連
-   [Video Processing Unit（動画処理装置）](https://www.digi.com/resources/documentation/digidocs/embedded/dey/3.0/cc6/bsp_r_video-vpu_cc6cc6qp)
    -   動画コーデックのハードウェアエンコーダー / デコーダーの別名だろうか

### WPU

-   [Wearable Processing Unit（ウェアラブル処理装置）](https://www.cnx-software.com/2014/06/05/ineda-systems-dhanush-wpu-is-a-mips-based-soc-specifically-designed-for-wearables/)
    -   ウェアラブルな演算装置

### XPU

-   [X Processing Unit（任意の処理装置）](https://www.intel.co.jp/content/www/jp/ja/architecture-and-technology/xpu.html)
    -   “X”に任意のアルファベットが入る、ナントカ処理装置
    -   つまりはこの記事で扱うものすべて

### YPU

-   [Y Processing Unit（任意の処理装置その２）](https://www.boj.or.jp/paym/outline/mirai_forum/data/rel211130d1.pdf)
    -   XPUをインクリメントしたもの
-   [YAMAHA Programming Unit（ヤマハプログラミング装置）](https://global.yamaha-motor.com/stories/history/products/img/robot/AP000178476.pdf)

### ZPU

-   [Zylin Processing Unit（ザイリン処理装置）](https://en.m.wikipedia.org/wiki/ZPU_\(processor\))
    -   ザイリン社製FPGAに載ってる処理チップらしい
